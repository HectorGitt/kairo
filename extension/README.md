# Kairo Chrome Extension

## Installation Instructions

1. **Download the Extension**
   - Download or clone this extension folder to your local machine

2. **Open Chrome Extensions**
   - Open Chrome browser
   - Navigate to `chrome://extensions`
   - Enable "Developer mode" (toggle in top right corner)

3. **Load the Extension**
   - Click "Load unpacked"
   - Select the Kairo extension folder
   - The extension should now appear in your browser toolbar

4. **Configure the Extension**
   - Click on the Kairo extension icon
   - Enter your API URL (e.g., `https://your-app.com/api`)
   - Enter your authentication token (found in the web app setup page)
   - Click "Save Settings"

5. **Start Using Kairo**
   - The extension will automatically track your browsing
   - You'll receive gentle nudges when spending too much time on distracting sites
   - View your insights on the Kairo web dashboard

## Features

- **Automatic Tracking**: Monitors time spent on different websites
- **Smart Categorization**: Classifies sites as productive, neutral, or distracting
- **Gentle Nudges**: Sends notifications when you've been distracted for too long
- **Real-time Sync**: Sends data to your Kairo dashboard for AI-powered insights

## Privacy

Kairo respects your privacy:

- No data is shared with third parties
- You can delete your data at any time
