-   **Architecture**: FastAPI backend, React frontend, MongoDB, Chrome extension.

-   **Authentication**: JWT username/password.

-   **Profile Management**: A dedicated Profile Settings page allows users to set up and modify their personalization preferences using an interactive, step-based form, view generated categorization rules, and receive attention health tips.
-   **UI/UX**: Shared navigation components, dynamic display of extension connection status, Kairo icon linking to homepage, and consistent design patterns.
